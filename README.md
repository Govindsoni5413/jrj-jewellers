## 💎 Features

- **Royal Couture Aesthetic**: Deep wine velvet palette, 3D card bevels, Playfair Display typography, starlight floating animations, and gold shimmer badges.
- **Interactive Shopping Bag / Cart Drawer**: Slide-out drawer with dynamic quantity adjustments, coupon discounts, GST computation, and insured courier checkout flow.
- **Interactive Saved Heirlooms (Wishlist)**: Real-time wishlist drawer with badge counter updates and quick move-to-bag capability.
- **Swarna Nidhi 10+1 Gold Savings Calculator**: Interactive range slider calculating 10-month patron deposits, complimentary 11th-month bonus from JR. JEWELLERS, and total maturity value.
- **VIP Consultation & Video Call Booking**: Modal with date/time picker, type of private viewing (Flagship lounge, Virtual AR, Armoured Valet Van), and instant reference code generation.
- **Flagship Boutique Locator & Pincode Checker**: 18 flagships across India with armed guard transit verification.
- **Product Quick-View Specification**: Live modal displaying net gold weights, stone carats, hallmarking certificate details, and price breakdowns.
- **Responsive Navigation**: Mobile-first luxury side drawer for smartphone viewports.
